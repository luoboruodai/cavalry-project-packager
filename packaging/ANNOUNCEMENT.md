## English announcement

**Pack the Scene. Keep the assets together.**

Cavalry Project Packager collects the file assets your Compositions actually use, preserves Smart Folder hierarchy, relinks the packaged Scene and validates the portable Project.

v0.1.2 refreshes the repository and delivery experience: bilingual landing pages, offline installation guides, a clean single-script ZIP, SHA-256 checksums and three-platform CI. The packaging and rollback behaviour remains the proven v0.1.1 implementation.

Download the MIT-licensed Cavalry UI Script:
https://github.com/luoboruodai/cavalry-project-packager/releases/tag/v0.1.2
